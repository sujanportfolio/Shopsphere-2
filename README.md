# ShopSphere Ecommerce - Real Images Edition

A lightweight React/Vite storefront with real product photography URLs.

## Run
Frontend:
cd frontend
npm install
npm run dev

Backend:
cd backend
npm install
npm run dev

Frontend: http://localhost:5173
Backend health: http://localhost:5000/api/health

The image URLs use Unsplash photography. For products you actually sell, replace demo photography with images you have permission to use.
